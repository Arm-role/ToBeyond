# แผน Domino Run (greybox → ระบบจริง)

ที่มา: หลักการ `docs/design-principles.md` + ข้อเสนอ advisor (2026-11-13). ทำเป็นเฟส เล่นผ่านก่อนลบของเดิม.
Greybox อยู่แยกจากเกมหลัก: `scenes/greybox.tscn` + `scripts/greybox/`, เปิดด้วย `?mode=greybox` (web) หรือ `-- --mode=greybox`. เกมเดิมไม่ถูกแตะ.

## แกนเกม
- แต่ละเทิร์น: มี Gem 3 ใบ (แดง = โจมตี, น้ำเงิน = โล่) วางลงช่อง 1×8 แล้วกดเดิน
- ลูกไฟวิ่งช่อง 1→8 Gem ป๊อปทันทีที่ผ่าน (เสียงสูงขึ้น จังหวะเร็วขึ้น)
- ศัตรูแสดง intent เป็นธงบนช่องหนึ่ง การตีเกิดตอนลูกไฟถึงช่องนั้น โล่นับเฉพาะที่ป๊อปก่อนถึง (รวมช่องธง)
- ตัดสินใจฐานมีข้อเดียว: Gem ไหนอยู่ก่อนธง Gem ไหนอยู่หลัง
- HP จริงทั้งสองฝั่ง

## เฟส
1. **Greybox** (ทำแล้ว): แดง/น้ำเงิน ไม่มี Artifact ศัตรูโตต่อด่าน เล่นดูว่า 10 ด่านแล้วยังอยากกดเดินไหม จูนจังหวะ/เสียงก่อนเพิ่มกฎ
2. **(ทำแล้ว) Artifact 3 ใบฮาร์ดโค้ด** (toggle ใน debug): กำแพงกระจก (เด้งกลับที่ช่อง 8), ถ่านไฟ (Gem อยู่ต่ออีกรอบ), ตอบโต้ (น้ำเงินบนช่องธงสะท้อนการตี) ดูว่าการวางเปลี่ยนจริงไหม
3. **Event + ภาษา Artifact**: การวิ่งส่ง event (Ignite, Pass, Strike, ReachEnd, Kill) Artifact = trigger + เงื่อนไข + ผล เป็นข้อมูล ใส่เพดาน Gem ป๊อปไม่เกิน 3 ครั้ง/รอบ และป๊อปซ้ำไม่ trigger ต่อ
4. **Artifact 12 ใบ** + เลือก 1 จาก 3 หลังชนะ (ยังไม่มีร้าน)
5. **ร้านและเหรียญ + บอส** ที่แต่ละตัวบิดกฎหนึ่งข้อ (ธง 2 อัน, ธงที่ย้ายเอง)
6. ลบระบบเก่าบน branch หลังพิสูจน์ว่าสนุก

## คอมโบที่ต้องระวัง
กำแพงกระจก+ตอบโต้ (บอสตายเอง → บอสตีครั้งเดียว/ธงย้ายไม่ได้), ป๊อปซ้ำวนไม่รู้จบ (เพดาน 3 ครั้ง), ถ่านไฟ+เตาเผา+สายชนวน (กระดานเต็มทุกรอบ → จำกัดเวลาวิ่ง ≤2.5 วินาที)

# หลักการออกแบบ (ตั้งเมื่อ 2026-11-13)

**Artifact คือ content หลักที่ผู้เล่นต้องคิดมากที่สุด ส่วนอื่นของเกมเป็นแค่ muscle memory**

## ความหมาย

| ส่วน | บทบาท | ข้อกำหนด |
|---|---|---|
| Artifact | ที่เดียวที่ผู้เล่นต้องคิดจริง: เลือกซื้อ จัดชุด วางลำดับ ผูกบิลด์ | ลึก มีปฏิสัมพันธ์ระหว่างใบ ทุกใบเปลี่ยนวิธีเล่น ไม่ใช่แค่ +ตัวเลข |
| Gem / มือ / กระดาน / เดิน | ทำซ้ำได้โดยไม่ต้องคิด | ค่าเดียว (ATK) อ่านได้ทันที ไม่มีกฎซ่อน ไม่มีสูตรต้องจำ |
| ร้านค้า / รางวัล | ส่ง Artifact ให้ผู้เล่นเลือก | ตัวเลือกคือ Artifact เป็นหลัก ของอย่างอื่นน้อยและอ่านง่าย |
| ศัตรู / HP | แรงกดดันที่ทำให้ Artifact มีความหมาย | intent เห็นล่วงหน้า ไม่ซับซ้อนเอง |

## ผลที่ตามมา (ยังไม่ได้ทำ ใช้เป็นเข็มทิศ)

1. Gem เหลือค่าเดียว = โจมตี สีและทิศเป็น "ป้าย" ให้ Artifact อ่าน ไม่ใช่ราง/กฎของตัว Gem เอง
2. กฎพื้นฐานที่ผู้เล่นต้องเรียนรู้ (สายสีเดียวกัน, attuned ×2) ถ้าเก็บ ต้องง่ายพอจนเป็นสัญชาตญาณ หรือย้ายไปเป็น Artifact
3. โล่ / รักษา / ทอง มาจาก Artifact ไม่ใช่จาก Gem
4. Artifact ต้องเป็นระบบ: มี trigger (ตก, เริ่มเดิน, ชนะ, วางการ์ด), เงื่อนไข (สี, ทิศ, ช่อง, เพื่อนบ้าน), ทรัพยากร (ATK, โล่, รักษา, เหรียญ) ให้ประกอบกันได้
5. อย่างน้อยครึ่งหนึ่งของ Artifact ต้องเปลี่ยนกฎ (เส้นทางเดิน ตำแหน่ง การแปลงทรัพยากร) ไม่ใช่แค่ +N ATK เพื่อไม่ให้เหมือน Balatro
6. ช่อง Artifact จำกัด (5) เพื่อให้การเลือกมีต้นทุน

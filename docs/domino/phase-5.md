# เฟส 5: เหรียญ ร้านค้า บอส

ต้องอ่านก่อน: `docs/plan-domino-run.md`, `docs/domino/phase-4.md` (ต้องเสร็จก่อน).
ไม่ทำ: ความก้าวหน้าข้าม run (meta progression).

## ขอบเขต
- เหรียญ: ชนะแต่ละด่านได้ 3 + ด่าน/2
- ทุกด่านที่ 3 เป็นบอส หลังบอสมีร้าน: Artifact 4 ใบ ราคา 4/6/8 ตามความหายาก, สุ่มใหม่ 2 เหรียญ (เพิ่มครั้งละ 1), ขายได้ครึ่งราคา
- ด่านปกติยังใช้เลือก 1 จาก 3
- กริยาใหม่ `gold{amount}` และ Artifact เศรษฐกิจ 2 ใบ: `piggy` 🐷 กระปุก (`kill`: +1 เหรียญต่อทุก 5 เหรียญที่ถือ สูงสุด 3) และ `bounty` 💰 ค่าหัว (`kill`: +2 เหรียญ)

## ไฟล์
- `scripts/domino/domino_boss.gd` (Resource): `id, name_th, hp_mult, dmg_mult, rule: StringName, args, rules: Array[Resource]` โดย `rules` เป็นของศัตรู ทำงาน **ก่อน** artifact ผู้เล่น
- `data/domino/bosses/*.tres`
- `scripts/domino/domino_shop.gd`

## บอส (หนึ่งกฎต่อตัว)
- `twin_flag` ธงคู่: มีธงสองอัน แต่ละอันตี 60% ของดาเมจ
- `drifter` ธงหนี: ทุกครั้งที่ตี ธงเลื่อนไปข้างหน้า 2 ช่อง และ `move_flag` ผลักไม่ได้
- `obsidian` กระจกดำ: การตีที่ถูกสะท้อนได้ดาเมจครึ่งเดียว
- `smoke` ม่านควัน: ซ่อนธงจนกว่าลูกไฟจะอยู่ห่าง 2 ช่อง (เฉพาะ view, sim ไม่เปลี่ยน)
- `bulwark` ป้อมเหล็ก: แดง 2 ป๊อปแรกของทุกรอบดาเมจ 0

## ลำดับงาน
เหรียญ → ร้าน → Resource บอสและ hook ใน sim (flags เป็น array, กฎศัตรูก่อน) → บอส 5 ตัว → regress ครอบคลุมบอสแต่ละตัวกับ mirror+riposte, ring และ push

## เสร็จเมื่อ
รัน 9 ด่านพร้อมบอส 3 ตัวและร้าน 3 ครั้งจบได้; บอสแต่ละตัวชนะคอมโบของเฟส 4 ได้อย่างน้อยหนึ่งคอมโบใน regress

## ความเสี่ยง / ถอยกลับ
ร้านอาจแย่งความสำคัญของการเลือก 1 จาก 3: ถ้าเล่นแล้วเป็นแบบนั้น ให้ร้านแทนการเลือกเฉพาะหลังบอส. ถอยกลับ: ธงปิดบอส (ทุกด่านเป็นด่านปกติ).
